YouTube Home Page Clone

A responsive YouTube Home Page Clone built using HTML, CSS, and Bootstrap. This project recreates the basic layout and visual design of the YouTube homepage as a frontend practice project.

📌 Project Description

This project is a clone of the YouTube Home Page, created to practice frontend development and responsive web design. It includes a YouTube-style navigation bar, search bar, sidebar, video thumbnails, and video cards.

🛠️ Technologies Used
HTML5
CSS3
Bootstrap 5

🎯 Purpose

This was my first frontend cloning project, created to improve my understanding of HTML, CSS, Bootstrap, webpage layouts, and responsive design.
